# 照片与内容维护

## 添加照片

把图片放到顶层「照片」文件夹，双击「导入照片.command」，再双击「预览网站.command」。

每张照片自动生成长边不超过 480、960、1600、2800 像素的 WebP，不放大。自动校正方向、保留构图、转为 sRGB、移除 EXIF。逐张处理，限制图像处理线程和缓存，适合本机大照片。

摄影页始终单列纵向滚动：横图较宽，竖图居中，展示高度适配屏幕。首张正常加载，后续延迟加载，点击才加载完整大图；照片不显示标题。

## 排序和首页照片

通常用文件名 `01-xxx.jpg`、`02-xxx.jpg` 排序。也可创建同名 JSON（格式见 `photo-metadata.example.json`），指定 `order`，数值越小越靠前。

`description` 是供读屏软件读取的无障碍描述，不在照片下显示。`homepage: true` 选择首页个人照片，最多一张；`published: false` 暂不展示。当前 UFO-1.PNG 已保留为首页照片。

## 内容与程序

「网站/src/data」保存公开的个人信息、双语文字、论文和自动摄影清单。「网站/src/pages」是页面；「网站/src/components」是共用内容；「网站/src/layouts」负责导航和页脚；「网站/src/styles」负责视觉。

`网站/public/photos/` 与 `网站/src/data/photos.json` 自动生成，请勿直接编辑。`网站/.local/build/` 是构建结果；`网站/.local/qa/` 是测试与截图；`网站/.local/cache/` 是缓存，这些都不发布。

用户原片不会进入 Git，但生成的展示图会随网站公开。移除已发布的照片不会抹去历史 Git 提交；请只加入已决定公开的照片。
