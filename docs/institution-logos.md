# Institution logos

标志用于标识个人的学习与任职经历，保留官方图形、颜色和比例。

- **NAOC**：国家天文台官网图标，https://nao.cas.cn/images/logoicon.png 。原图 104×72，完整显示。
- **Peking University**：标识管理办公室发布的圆形红色校徽，https://vim.pku.edu.cn/xzzq/index.htm ，下载包 https://vim.pku.edu.cn/docs/20240527144201516364.zip 中的「标志_红色.png」，原图 360×360。
- **MPE**：MPE 官网页头使用的 Max Planck Society Minerva 标志，从官方 SVG 的独立 Minerva 图组保留为紧凑矢量文件，未重绘路径或改变颜色。来源：https://www.mpe.mpg.de/assets/institutes/headers/mpe-mobile-en-79589f5f125d8fb5e8905c694c2929a71a6d32c38add68de4f8cd0b6ce150a58.svg 。
- **Zhengzhou University**：官网文化标识页面的校徽，https://www15.zzu.edu.cn/xxgk/whbs.htm ，图像 https://www15.zzu.edu.cn/__local/F/09/A3/7C2002C534020EAD7036D42F848_DB67C5F8_AC59.png ，原图 252×252。

资源存放于 website/public/logos/。图像在机构名称旁作为装饰显示；读屏软件直接读取机构名称，不重复朗读标志。

导师姓名的拼写与公开身份核对：吴宏的官方介绍 https://www.nao.cas.cn/nrc/zg/202204/t20220406_6986004.html ，英文名单 https://english.nao.cas.cn/scientist/ ，吴学兵的官方介绍 https://kiaa.pku.edu.cn/info/1010/1008.htm ，Mara Salvato 的主页 https://www.mpe.mpg.de/~mara/ 。导师关系及 MPE 身份由用户直接确认。
